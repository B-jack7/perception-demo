# Technical Route

## Main research question

> Does active multi-view RGB-D scanning improve 3D scene completeness and spatial-language grounding accuracy compared with a single overhead view in tabletop robotic manipulation?

## System architecture

```text
Language command + initial overhead RGB-D
                    ↓
Initial metric point cloud in robot-base frame
                    ↓
Completeness and uncertainty check
                    ↓
Optional wrist-camera viewpoints
                    ↓
TF coarse registration → constrained ICP → voxel/TSDF fusion
                    ↓
Table removal → 3D clustering → object instances
                    ↓
Geometry + colour + multi-view CLIP/SigLIP classification
                    ↓
Semantic 3D scene graph
                    ↓
Language → structured graph query → target selection
                    ↓
Grasp/placement planning → MoveIt 2 / ROS 2
                    ↓
Fresh RGB-D verification → incremental map update
```

## Perception output

Each object node should include:

```json
{
  "id": "cup_1",
  "category": "cup",
  "position_base_m": [-0.30, 0.07, 0.10],
  "dimensions_m": [0.26, 0.20, 0.20],
  "geometry_evidence": "hollow cylinder + handle",
  "views_used": 4,
  "semantic_confidence": 0.91
}
```

Spatial relations are computed from metric geometry rather than generated by a language model:

```json
{
  "subject": "cup_1",
  "relation": "left_of",
  "reference": "cube_1",
  "reference_frame": "robot_base"
}
```

## Recognition strategy

- Point-cloud geometry supplies position, dimensions and primitive-shape evidence.
- Multi-view RGB crops supply colour and semantic appearance.
- CLIP/SigLIP scores label already-separated 3D instances; they do not generate coordinates.
- Low-confidence classifications remain `unknown` and may trigger another observation.

## Hardware assumptions

The full route requires Platform A with Gemini 335 overhead depth, Gemini 305 wrist depth and access to SO-101 joint states. If the wrist depth camera is unavailable, the fallback is single-view RGB-D with geometric priors and explicit uncertainty.

## Evaluation

- 3D centroid and dimension error
- Point-cloud registration error
- Visible-surface coverage
- Instance-separation success rate
- Semantic classification accuracy
- Spatial-relation accuracy
- Language target-selection accuracy
- Observation count and total latency
- Final manipulation success rate
